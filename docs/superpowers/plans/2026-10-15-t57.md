# T57 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Complete both persistent local leaderboards and their menu/result screens.
**Architecture:** Immutable result snapshots grouped by launch conditions; independent combat/knowledge best records in an atomic JSON store. A separate clock tracks ranking time, and the existing campaign UI hosts a focused leaderboard screen.
**Tech Stack:** Unity 6000.3.24f1, C#, Unity UI, NUnit EditMode/PlayMode.
**Spec:** [Approved T57 rules](../../t57-bang-xep-hang.md).

## Global Constraints

- Five combat criteria in BR-24 order; competition ranks 1, 1, 3; stable ordinal profile IDs.
- Only valid wins; separate best attempts for combat/knowledge; equal replay preserves earlier record.
- Partition by mission, difficulty, content version, rules version and launch upgrades.
- Pause/quiz/focus loss count; mandatory exclusions never count twice; integer milliseconds rounded nearest, midpoint up.
- Preserve shared method signatures, real user profiles and unrelated local changes. Offline only; no T62.

## Review Focus

- Corrupt main/backup: do not silently erase old records; report or recover backup.
- Write failure: roll back memory, retain previous file, retry idempotently.
- Profile/settings change mid-run: keep launch snapshot.
- Long names and many records: fit rows, preserve global ranks across pages.
- Overlapping exclusions and pause during tutorial: union exclusions, count pause during combat.
