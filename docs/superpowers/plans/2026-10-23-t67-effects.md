# T67 Effects Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Complete the approved lightweight combat effects and scene fades, with measured firing performance.

**Architecture:** Scene-owned fixed particle pools provide flash, dust, sparks, blast and smoke. A persistent transition canvas handles fades using unscaled time. Gameplay calls these only for presentation.

**Tech Stack:** Unity 6000.3.24f1, URP, C#, Unity Test Framework.

**Spec:** ../specs/2026-10-23-t67-design.md

## Global Constraints

- No imported effects pack; retain authored effect overrides and existing fog.
- No gameplay randomness consumed, damage/ammunition/rules changed, or audio changed.
- Bounded objects and particles; no more than 5 FPS decrease in matched firing runs.
- Work in the existing clean develop checkout to verify the approved change in the already-open Unity project; no publication is authorized.

## Review Focus

- Scene loads during pause must finish without leaving input blocked.
- Repeated transition clicks must cause a single load.
- Smoke must survive destruction of its emitting object and expire.
- Sustained fire must not grow the pool or change UnityEngine.Random state.
- Player flashes must not obstruct the scoped view; materials must render in URP/player builds.
